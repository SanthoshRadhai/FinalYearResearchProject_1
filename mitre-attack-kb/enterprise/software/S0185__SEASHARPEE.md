# S0185: SEASHARPEE

**Type:** malware  
**Reference:** https://attack.mitre.org/software/S0185  
**Aliases:** SEASHARPEE  
**Platforms:** Windows  

## Description
[SEASHARPEE](https://attack.mitre.org/software/S0185) is a Web shell that has been used by [OilRig](https://attack.mitre.org/groups/G0049). (Citation: FireEye APT34 Webinar Dec 2017)

## Techniques Used
- T1059.003: Windows Command Shell
- T1070.006: Timestomp
- T1105: Ingress Tool Transfer
- T1505.003: Web Shell
