# S1224: CASTLETAP

**Type:** malware  
**Reference:** https://attack.mitre.org/software/S1224  
**Aliases:** CASTLETAP  
**Platforms:** Network Devices  

## Description
[CASTLETAP](https://attack.mitre.org/software/S1224) is an ICMP port knocking backdoor that has been installed on compromised FortiGate firewalls by [UNC3886](https://attack.mitre.org/groups/G1048).(Citation: Mandiant Fortinet Zero Day)

- T1573.001: Symmetric Cryptography
- T1573.002: Asymmetric Cryptography
