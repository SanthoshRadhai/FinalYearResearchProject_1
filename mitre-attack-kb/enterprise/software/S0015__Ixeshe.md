# S0015: Ixeshe

**Type:** malware  
**Reference:** https://attack.mitre.org/software/S0015  
**Aliases:** Ixeshe  
**Platforms:** Windows  

## Description
[Ixeshe](https://attack.mitre.org/software/S0015) is a malware family that has been used since at least 2009 against targets in East Asia. (Citation: Moran 2013)
