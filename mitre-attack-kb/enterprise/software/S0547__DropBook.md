# S0547: DropBook

**Type:** malware  
**Reference:** https://attack.mitre.org/software/S0547  
**Aliases:** DropBook  
**Platforms:** Windows  

## Description
[DropBook](https://attack.mitre.org/software/S0547) is a Python-based backdoor compiled with PyInstaller.(Citation: Cybereason Molerats Dec 2020)
