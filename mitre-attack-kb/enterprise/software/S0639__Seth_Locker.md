# S0639: Seth-Locker

**Type:** malware  
**Reference:** https://attack.mitre.org/software/S0639  
**Aliases:** Seth-Locker  
**Platforms:** Windows  

## Description
[Seth-Locker](https://attack.mitre.org/software/S0639) is a ransomware with some remote control capabilities that has been in use since at least 2021.
(Citation: Trend Micro Ransomware February 2021)

## Techniques Used
- T1059.003: Windows Command Shell
- T1105: Ingress Tool Transfer
- T1486: Data Encrypted for Impact
