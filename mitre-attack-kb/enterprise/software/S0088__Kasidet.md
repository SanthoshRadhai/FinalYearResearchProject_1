# S0088: Kasidet

**Type:** malware  
**Reference:** https://attack.mitre.org/software/S0088  
**Aliases:** Kasidet  
**Platforms:** Windows  

## Description
[Kasidet](https://attack.mitre.org/software/S0088) is a backdoor that has been dropped by using malicious VBA macros. (Citation: Zscaler Kasidet)
