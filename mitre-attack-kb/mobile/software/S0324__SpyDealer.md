# S0324: SpyDealer

**Type:** malware  
**Reference:** https://attack.mitre.org/software/S0324  
**Aliases:** SpyDealer  
**Platforms:** Android  

## Description
[SpyDealer](https://attack.mitre.org/software/S0324) is Android malware that exfiltrates sensitive data from Android devices. (Citation: PaloAlto-SpyDealer)
