# CWE-1110: Incomplete Design Documentation

**Abstraction:** Base  
**Status:** Incomplete  
**Reference:** https://cwe.mitre.org/data/definitions/1110.html  

## Description
The product's design documentation does not adequately describe control flow, data flow, system initialization, relationships between tasks, components, rationales, or other important aspects of the design.

## Related Weaknesses
- ChildOf: CWE-1059

## Common Consequences
- Scope: Other; Impact: Reduce Maintainability
- Scope: Other; Impact: Increase Analytical Complexity
